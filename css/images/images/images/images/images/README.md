# Website giới thiệu cơ cấu tổ chức chính phủ Việt Nam

Website tĩnh được xây dựng bằng HTML5 và CSS3, bao gồm 5 trang:
- Trang chủ
- Giới thiệu
- Cơ quan nhà nước
- Quản lý nhà nước
- Liên hệ

## Yêu cầu
- HTML5
- CSS3
- Responsive cho máy tính và điện thoại
- Sử dụng đường dẫn tương đối
- Có giao diện thống nhất và nội dung rõ ràng

## Triển khai GitHub Pages
1. Upload toàn bộ mã nguồn lên GitHub.
2. Vào Settings > Pages.
3. Chọn mục: Deploy from a branch.
4. Branch: `main` và folder: `/root`.
5. Lưu lại và chờ GitHub Pages build hoàn tất.
